# design-sync notes — Rezet

- No published component library: `app/` is a Vite app, not an npm package with a build/`main`/`module`/`exports`. Using **synth-entry mode**: `cfg.entry` points at `app/dist/index.js` (deliberately nonexistent) purely so the converter walks up from it to find `app/package.json` and anchor `PKG_DIR = app/`. Component source comes from `cfg.srcDir = "src/ui"` (`app/src/ui/*.tsx`), scanned for PascalCase value exports.
- Scope is intentionally `app/src/ui/` primitives only (25 components: Button, IconButton, Card, ListCard, Row, Eyebrow, SectionHeader, StepNumber, Chip, OptionChip, Pill, Stepper, CheckRow, SegmentedControl, Toast, SearchField, TextField, PushHeader, ScreenBody, ScreenHeader, Sheet, AlertDialog, IngredientNameField, Icon, Pressable). Screens (`src/screens/`) and sheets (`src/sheets/`) are app-specific compositions, not design-system components, and were left out of scope.
- Chromium render check initially failed here (missing `libnspr4`/`libnss3`/etc, `sudo` has no TTY in this environment) but **worked on a later run without any environment change** — cause unconfirmed (possibly a stale/racy first attempt). If a future sync hits `[RENDER_SKIPPED]` again, retry once before concluding it's actually blocked; if it's really blocked, `npx playwright install-deps chromium` needs an interactive terminal with sudo.
- All 25 components have **authored previews** (`.design-sync/previews/<Name>.tsx`, committed) with real usage composition (Spanish content matching the app's domain — recipes/pantry), captured and graded `good` on the absolute rubric (styled/complete/plausible) — verified visually via `.review.html` contact sheets before upload.
- `Sheet` and `Toast` previews wrap their root in `{ transform: 'translateZ(0)' }` — both components are `position: fixed` internally (bottom-sheet / toast), which otherwise anchors against the real page viewport instead of the preview card and renders blank. See the comment in each `.tsx`.
- `PushHeader` and `ScreenHeader` are `cfg.overrides.<Name>: {"cardMode":"column"}` — both render wider than a multi-column grid cell (sticky header / screen title bar).
- `Sheet` and `AlertDialog` are `cfg.overrides.<Name>: {"cardMode":"single","viewport":"..."}` — overlay dialogs.
- `[FONT_MISSING] "SF Pro Text"`: accepted as a substitute (falls back to system-ui/sans-serif in the DS pane). SF Pro is Apple's proprietary system font — it isn't legally distributable as a shipped `.woff2` anyway. User confirmed accepting the substitute (2026-09-06).
- `README.md` §"Qué falta" (repo root) and `CLAUDE.md`'s non-negotiable rules (accent/warn vs accent-ink/warn-ink/onaccent, no themed component libraries, `--accent`/`--warn` are fills) fed `.design-sync/conventions.md` — validate real class/var names against `app/src/styles/tokens.css` before trusting that file on any future edit.

## Re-sync risks

- 15 of 25 components were **not src-matched** by the fuzzy-find (only 10 matched, all now `general` group) — they got no JSDoc/group enrichment. Re-grouping later: either add real per-component doc comments in `src/ui/*.tsx`, or pin `componentSrcMap`/`docsMap` entries in `config.json`.
- `entry: "app/dist/index.js"` is a deliberately-fake path (see note above) — if `app/` ever gets a real library build with that exact output path, the converter will silently switch from synth-entry to treating that file as the real dist bundle. Sanity-check the next sync's log line (`[NO_DIST] ... synthesizing from N src files` should still print) if `app/package.json` ever grows a real build script.
- No provider/context needed for any of these 25 components today (verified: no `useContext`/`useStore`/`usePrefs` in `src/ui/`). If a future primitive reads from `PrefsProvider` or the i18n context, `cfg.provider` will need setting or its preview will render blank.
- `IngredientNameField`'s suggestion dropdown (`open` state) can't render statically in a story — it only opens on focus. The authored preview shows the closed field with a value, which is honest but doesn't demonstrate the dropdown; a future sync could add a `WithSuggestionsOpen` cell only if the component gains a way to force it open via props.
